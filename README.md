# 量子通信标准中文库（Quantum Standards ZH）

非官方的量子通信（QKD / QKDN）标准中文翻译、解读与索引仓库。

> 配套公众号：QuantumStack（微信内搜索）

## 为什么建这个仓库

- 量子通信标准分散在 ITU-T、ETSI、ISO/IEC、国内 GB/T / YD/T / GM/T 等多个体系，缺少一个汇总索引；
- ITU 官网仅部分建议书提供官方中文版，且术语与国内工程习惯存在差异；
- 工程视角的解读（网络怎么组、控制面怎么设计、网管怎么纳管）几乎空白。

本仓库希望成为中文世界里量子通信网络工程师的入口：**索引 → 翻译 → 术语 → 解读**。
